# Groove Studio

> 🚧 Work in progress

Web application for music studio booking and management.

## Stack
- PHP / Laravel
- MySQL
- Docker

## Features (planned)
- Studio reservation system
- Session management
- Client & employee dashboard

## Author
Thomas Sajus

Startup
=============

Lancer la base et les scripts de création et remplissage de la base:
- docker-compose up -d

Arrêter la base et vider le container
- docker-compose down -v
